# Tennis Groups

Application Android hors ligne pour organiser des tournois amicaux de tennis en double.

## Fonctionnalités prévues
- Participants avec niveaux facultatifs de 1 à 5.
- Rotations continues et groupes de quatre inédits en priorité.
- Équilibrage des deux équipes de double lorsque les niveaux sont activés.
- Répartition équitable des temps de jeu et des pauses.
- Terrains multiples, chronomètre et historique local.
- Interface multilingue : français, anglais, espagnol, italien, portugais, allemand, chinois simplifié, japonais, hindi, néerlandais, russe, tchèque et serbe.

## Développement
- Kotlin, Jetpack Compose, Material 3
- Room pour le stockage local
- Aucune connexion ni compte requis

Le projet est initialisé progressivement. Voir les prochains commits pour l'implémentation fonctionnelle.
